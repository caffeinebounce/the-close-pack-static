# Skill: month-end checklist

Run this after the last banking day of the period. Do not start if last month is still open.

## 1. Cutoff

- [ ] All posted bank lines through period-end are imported
- [ ] No pending cards were posted
- [ ] Transfers between own accounts net to zero

## 2. Ledger

- [ ] Bank reconciliation is complete or every difference is on the exception list
- [ ] Bills and invoices that belong in the period are dated in the period
- [ ] Payroll, sales tax, and loan accounts roll forward from last month
- [ ] Owner draws / contributions are on equity, not expense

## 3. Review

- [ ] P&L makes sense in one paragraph
- [ ] Cash page ties to the bank
- [ ] Exception table is honest (empty is allowed)

## 4. Package

- [ ] Render the three-page close package
- [ ] Export a trial balance
- [ ] Stamp the period `final` or leave it `draft` with a reason

Lock the period in the ledger if your product supports it. Then stop touching it.
